# Wordle in Java

A Java-based recreation of the popular word-guessing game, Wordle. In this game, players guess a secret five-letter word within six attempts, receiving feedback on their guesses in the form of color-coded hints.

## Features

- **Word List**: A predefined list of valid five-letter words.
- **Random Word Selection**: Mechanism to select a random word from the list for each game.
- **Guessing Logic**: Allows the player to make guesses.
- **Feedback System**:
  - **Green**: Correct letters in the correct position.
  - **Yellow**: Correct letters in the wrong position.
  - **Gray**: Incorrect letters.
- **Game State Management**: Handles game state and end conditions (win or lose).

## Requirements

- **Java JDK**: Version 11 or higher.
- **IDE**: NetBeans IDE or any other Java IDE.
